Setup Guide

How to use

  1. Add domain overrides in the "Domain Overrides" tab
  2. Start the DNS server: node dnsServer.js
  3. Configure dnsmasq to forward to this server on the configured port
  4. Point your clients to use the dnsmasq router as DNS

dnsmasq Configuration

# /etc/dnsmasq.conf
server=YOUR_SERVER_IP#6767

Notes

  • Changes to config.json are automatically reloaded by the DNS server
  • Browsers with DNS-over-HTTPS may bypass system DNS
  • Only A, AAAA, and CNAME records are supported for overrides
